① Thompson Construction ε-NFA
② ε-NFA → DFA (Subset Construction)
Algorithm: For each set of NFA states reachable via a symbol, compute its ε-closure to form a new DFA state. Repeat until no new states are discovered. A DFA state is accepting if any NFA state in its set is an accept state.
③ DFA → Min-DFA (Hopcroft's Algorithm)
Partition Refinement: Start with two groups — accepting and non-accepting states. Repeatedly split groups whose states disagree on transitions. When no more splits occur, each group becomes one minimal-DFA state.
